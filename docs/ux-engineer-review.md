# LMS Frontend UI/UX Audit & Improvement Report

Act as a Senior Product Designer, UX Researcher, and Senior Frontend Engineer.

This project is a Learning Management System (LMS) built using React, Vite, and JSX.

Your task is NOT to review code quality or architecture.

Your task is to evaluate the application from the perspective of:

- Students
- Instructors
- Administrators

Analyze the UI, UX, workflows, usability, consistency, accessibility, and overall product experience.

Assume the goal is to build a modern LMS comparable to platforms such as Coursera, Udemy, Moodle, Canvas, Teachable, and TalentLMS.

---

## Review Process

Explore the entire application.

Navigate through all pages and user flows.

Document:

- Screens reviewed
- User journeys reviewed
- UX issues discovered
- UI inconsistencies discovered
- Missing product features
- Areas causing friction

Do not focus on code.

Focus on user experience.

Generate a detailed markdown report.

For every issue found provide:

- Severity (Critical / High / Medium / Low)
